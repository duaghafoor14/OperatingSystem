# Operating System

Lab tasks, reports and practice work for the **Operating System** course  
BS Software Engineering, HITEC University, Taxila

**Author:** Dua Ghafoor

## About

This repository keeps my Operating System lab work in one place: task solutions, shell commands, terminal outputs and report drafts. The labs are done on **Ubuntu Linux**, using GitHub Codespaces or WSL.

## Topics Covered

- Linux terminal vs shell
- Basic Linux commands (`pwd`, `cd`, `ls`, `mkdir`, `cp`, `mv`, `rm`, `cat`, `touch`)
- File ownership and permissions (`chmod`, `chown`, `chgrp`)
- Viewing, sorting and combining files (`cat`, `sort`, `head`, `tail`)
- I/O redirection (`>`, `>>`, `<`, `2>`)

## How to Run

1. Open this repo on GitHub, click **Code → Codespaces → Create codespace on main**.
2. Use the terminal at the bottom (it runs Ubuntu).
3. Run the commands from each lab folder.
